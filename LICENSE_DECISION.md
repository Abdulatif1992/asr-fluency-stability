# Licensing decision needed before public release

The user is the copyright holder of their original project code. No permission
license was selected by the owner, so this repository intentionally does not
assert an MIT, Apache-2.0 or other open-source license.

Before making the repo public:
1. Choose a code license (e.g. MIT) if you want others to reuse your scripts.
2. Independently review the SpeechOcean762 dataset license and redistribution
   terms for derived transcripts, labels and any copied metadata.
3. Check third-party model and package licenses; do not publish raw audio here.
4. Remove personal/sensitive material and review the complete Git history.
